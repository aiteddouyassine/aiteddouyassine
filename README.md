MS Financial Engineering at USC, with an undergraduate background in computer

**What I'm building**

- **[portfolio-risk-engine](https://github.com/aiteddouyassine/portfolio-risk-engine)** —
  Value-at-Risk and Expected Shortfall estimation with Kupiec coverage and
  Christoffersen independence backtests. All three models were rejected on real
  data; the breaches cluster, which points at conditional volatility rather than
  the distributional assumption everyone reaches for first.

- **[backtesting-engine](https://github.com/aiteddouyassine/backtesting-engine)** —
  Event-driven backtester with walk-forward optimization, parameter sweeps, and
  Monte Carlo trade reshuffling. The strategy it tests wins 72% of its trades and
  has no edge before costs. That result is the point.

Both projects are built around the same idea: the interesting question is not
whether a model produces a number, but whether the number survives being tested.
